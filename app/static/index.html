O que é Few-Shot Prompting na Engenharia de Software?

Few-Shot Prompting (ou aprendizado com poucos exemplos) é uma técnica de Engenharia de Prompt onde fornecemos alguns exemplos explícitos de entradas e saídas esperadas no corpo do prompt para condicionar e guiar o modelo de linguagem (LLM).

Por que Usar?

Modelos de linguagem às vezes falham em seguir formatos de saída complexos (como JSONs rígidos, esquemas de banco de dados ou chamadas REST precisas) se receberem apenas instruções abstratas (Zero-Shot). Ao dar 2 a 5 exemplos reais, o modelo captura o padrão estrutural e de tom com precisão impecável.

Casos de Uso em Software

Excelente para converter logs brutos em relatórios formatados, traduzir linguagem natural de usuários em comandos de API (nosso caso de estudo), gerar código padronizado com arquitetura corporativa, ou criar scripts de testes unitários específicos.

Estrutura Anatômica de um Prompt Few-Shot

Um prompt few-shot de qualidade industrial possui quatro seções cruciais:

  1. Instrução/Papel (System Prompt): Define quem o modelo é e qual sua tarefa principal (ex: "Você é um interpretador que traduz comandos em chamadas de API de férias").
  2. Contexto/Regras: Explica os limites do sistema, formatos aceitos e esquemas de payload (ex: explicar as rotas e tipos de dados da nossa API).
  3. Demonstrações (Few-Shot Examples): A alma do prompt. Pares de entrada e saída claramente delimitados.
  4. Entrada do Usuário (Input): O novo comando a ser processado, no mesmo formato dos exemplos anteriores, aguardando a finalização da LLM.
